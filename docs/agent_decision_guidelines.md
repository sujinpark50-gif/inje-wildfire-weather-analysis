# 산불 프로젝트 총괄 에이전트 판단 지침

## 목적과 현재 판단

총괄 에이전트는 자료가 뒷받침하는 범위에서 분석 질문을 정하고, 관측 결과와 문헌의 해석을 구분하여 보고서를 완성한다. 원하는 결론이 나오지 않는다는 이유로 기준을 바꾸거나 산불 사례를 추정해 만들지 않는다. 이 지침은 과제의 분석·검토용이며 현장 산불 경보나 대피 판단을 대신하지 않는다.

현재 프로젝트에서는 **인제 ASOS 1개 지점의 365일 자료로 산불 관련 기상요인의 변화를 탐색할 수 있다. 그러나 인제에서 산불이 언제 많이 발생했는지, 기상요인이 발생 확률을 얼마나 높였는지는 아직 판단할 수 없다.** 실제 산불 발생 기록이 결합되지 않았기 때문이다. 공식 강풍 수치 기준 충족이 0일이라는 결과는 그대로 유지한다.

## 논문을 판단에 사용하는 방법

아래 내용은 KCI에서 확인한 저자 초록에 근거한다. 총괄 에이전트의 운영 원칙은 그 내용을 현재 프로젝트에 적용한 판단이며, 논문이 직접 제시한 에이전트 운영 규칙은 아니다.

## 질문별 분석 허용 범위

| 질문 | 필요한 근거 | 현재 결정 |
| --- | --- | --- |
| 건조하거나 바람이 상대적으로 강한 시기는 언제인가? | 정렬된 기상 시계열, 누락 점검, 월별 통계, 지표 정의 | 진행 가능. 실제 산불 시기와 구분해 관측 수치로 답한다. |
| 습도와 풍속 자체는 관련이 있는가? | 같은 날짜의 연속값 산점도·상관계수, 계절별 비교 | 별도 분석 후 판단한다. 현재의 특보 기준 교집합 0일만으로 무관하다고 결론내리지 않는다. 상관이 있어도 인과로 해석하지 않는다. |
| 건조와 강풍 기준이 같은 날짜에 충족되는가? | 정의된 임계값·지속 조건과 일별 판정 | 기존 계산을 유지한다. 같은 날짜와 같은 시각은 구분한다. |
| 산불은 언제 많이 발생했는가? | 같은 지역·기간의 발생일시·위치·건수 및 기록의 수록 범위 | 판단 보류. 문헌의 전국 경향만 별도 소개한다. 산불 기록이 없다는 것을 산불 0건으로 처리하지 않는다. |
| 습도·풍속이 산불 발생 확률과 관련되는가? | 산불 발생일과 비발생일, 다년 기상자료, 계절·기온 등 다른 요인 | 자료 확보 후 분석한다. 산불이 난 날만 모아 발생 확률을 계산하지 않는다. |
| 바람이 피해를 얼마나 키웠는가? | 피해면적, 발화 이후 시간별 기상, 지형·연료·진화 조건 | 현재 자료로 판단 보류. 일별 기상 극값만으로 피해 증가를 추정하지 않는다. |

## 자료와 기준에 대한 결정 규칙

1. **변수를 먼저 확인한다.** 상대습도와 실효습도, 평균풍속과 최대풍속·최대순간풍속은 서로 대체하지 않는다. 논문 모형을 적용하려면 관측 높이, 평균 시간, 공간 범위, 계산식까지 확인한다. 초록만으로 불명확하면 모형 적용을 보류하고 원문 확인 대상으로 기록한다.
2. **공식 특보와 산불 모형을 구분한다.** 기상청 건조·강풍 기준은 기상특보의 비교 기준이다. 산불 발생의 필요·충분조건으로 사용하지 않는다. 논문의 제안 기준을 현재 공식 운영 기준이라고 소개하지 않는다.
3. **결측치의 의미를 확인한 뒤 처리한다.** 이번 강수량 빈값은 무강수로 확인되지 않았으므로 0으로 채우지 않는다. 4월 23일 일조시간은 인근 관측소 값으로 대체하지 않는다. 새 보완 자료가 생기면 변경 근거와 전후 영향을 기록한다.
4. **극값은 우선 보존한다.** IQR 후보는 검토 표시다. 관측 오류 근거가 없으면 높은 풍속을 삭제하지 않는다. 원본은 보존하고 파생 자료에서 처리 이력을 남긴다.
5. **사례가 없거나 적은 결과도 결과로 인정한다.** 특보 충족 0일을 이유로 임계값을 사후 완화하지 않는다. 분위수 등 다른 정의가 질문에 필요하다면 목적을 먼저 명시하고 탐색 분석으로 별도 보고한다.
6. **공간·시간 해상도를 넘어서 주장하지 않는다.** 인제 ASOS를 인제군 전체 산지의 관측값으로 취급하지 않는다. 일최저습도와 일최대풍속이 같은 시각에 발생했다고 가정하지 않는다. 자료를 결합할 때는 발화 이후 관측을 사전 예측 변수로 섞지 않는다.

## 결과 검토와 보고 기준

총괄 에이전트는 모든 결론을 다음 네 종류로 표시한다.

- **관측·계산 결과:** 원본 및 재현 가능한 산출물로 확인한 수치.
- **문헌 결과:** 저자·연도·대상·링크가 명시된 다른 연구의 결과.
- **해석:** 관측 결과와 문헌을 연결한 설명으로, 검증된 사실과 구분한다.
- **미확인:** 필요한 자료나 검증이 없어 보류한 내용.

최종 검토에서는 행 수·날짜 누락·단위·집계 합계·임계값 포함 여부를 확인한다. 시각화는 날짜 축, 축 범위, 일별·월별 선택 이유를 검토한다. 예측 모형을 추가하면 시간 순서를 지킨 평가 자료를 분리하고 단순 기준 모형과 비교한다. 드문 산불을 항상 없다고 예측해 얻는 높은 정확도만으로 성능을 평가하지 않는다. 이러한 검증을 하지 않았다면 했다고 쓰지 않는다.

인사이트마다 관측 수치와 해당 표·그림을 연결한다. 문헌 요약만을 이 데이터에서 새로 도출한 인사이트로 세지 않는다. AI 사용 로그에는 검색·코드·해석에 사용한 이유와 실제 수행한 검증을 기록한다.

## 현재 자료에 적용한 판단 예시

> 관측 결과: 실효습도 35% 이하가 2026년 2월 23~24일에 이어졌으며, 강풍특보 수치 기준 충족은 0일이었다. 4월 월평균 실효습도는 48.68%로 9월 68.69%보다 낮았다. 문헌 결과: 국내 장기 연구는 봄철 산불 집중 및 여러 기상요인과의 관련성을 보고한다. 해석: 이번 자료는 산불 관련 기상요인의 연중 변화를 설명하는 데 활용할 수 있다. 미확인: 실제 산불 기록이 없으므로 인제의 산불 집중 시기와 발생 확률을 검증하지 못했다. 습도·풍속 사이의 관계도 현재 기준 충족 분석만으로 판정하지 않는다.

총괄 에이전트는 위 판단에 따라 기존 기상 분석을 유지하고 문헌 검토를 보완한다. 산불 빈도·예측·피해 분석은 관련 기록을 확보한 뒤 진행한다. 보고서의 완성도는 위험 사례가 많이 나오는지가 아니라 질문·자료·방법·결론이 서로 맞는지로 평가한다.
